## ✨ Реализованный функционал
1. **Шапка с навигацией** – логотип, ссылки (якоря на разделы), кнопка переключения темы.
2. **Сетка карточек фильмов** – построена на CSS Grid, адаптивна под любые экраны.
3. **Кнопка «Показать ещё»** – добавляет 4 новых фильма при каждом нажатии, блокируется после загрузки всех.
4. **Тёмная тема** – переключение с сохранением состояния в `localStorage`. Переключатель меняет иконку.
5. **Форма обратной связи** – валидация полей (имя, email с проверкой формата, сообщение). При успешной отправке данные выводятся в `console.log`, форма сбрасывается.
6. **Подвал** – ссылки на соцсети (иконки), копирайт.
7. **Адаптивность** – мобильные стили, медиазапрос для устройств до 768px.
8. **Плавный скролл** – при клике на навигацию (через якоря), а также при загрузке новых фильмов страница прокручивается к началу блока.

## 🔧 Запуск проекта локально
1. Скачайте файл `index.html`.
2. Откройте его в любом современном браузере (Chrome, Firefox, Safari).
3. Для проверки работы консоли откройте DevTools (F12) → вкладка Console.

## 🌐 Публикация на GitHub Pages (инструкция)
1. Создайте репозиторий на GitHub.
2. Загрузите файл `index.html` в корень репозитория.
3. Перейдите в **Settings → Pages**.
4. В разделе **Branch** выберите `main` (или `master`) и папку `/ (root)`.
5. Нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:  
   `https://ваш-username.github.io/имя-репозитория/`

## 📝 Примечания
- Постеры фильмов взяты с открытого API TMDB (themoviedb.org). Реальные изображения загружаются по URL. Если картинка недоступна, подставляется плейсхолдер.
- Все данные о фильмах (название, год, рейтинг) заданы вручную — API-ключ не требуется.
- Форма не отправляет данные на сервер, только в консоль — это соответствует техническому заданию.
