# 🎧 MusicWave — музыкальный стриминг-лендинг

Современный одностраничный сайт с подборкой популярных треков, тёмной темой и формой обратной связи.  
Проект выполнен в рамках итогового задания по веб-разработке.

## 🎯 Цель проекта
Создать адаптивный интерактивный сайт музыкальной тематики, соответствующий требованиям:
- семантическая вёрстка (`<header>`, `<main>`, `<footer>`);
- шапка с навигацией, блок с карточками треков, форма обратной связи;
- динамическая подгрузка карточек («Показать ещё»);
- переключение светлой/тёмной темы с сохранением в `localStorage`;
- валидация формы и вывод данных в `console.log`.

---

## 🛠️ Технологии
- **HTML5** – семантическая разметка
- **CSS3** – Flexbox, Grid, CSS-переменные, адаптивный дизайн, hover-эффекты
- **JavaScript** – динамическое создание карточек, обработка событий, валидация, localStorage
- **Google Fonts** – шрифт Inter
- **Изображения** – заглушки (placeholder) и внешние обложки (с возможностью замены)

## ✨ Функционал

### Обязательные разделы
| Раздел | Описание |
|--------|----------|
| Шапка с навигацией | Логотип, ссылки на разделы, кнопка переключения темы |
| Блок с карточками треков | Исполнитель, год, рейтинг, количество прослушиваний |
| Форма обратной связи | Поля: имя, email, сообщение; валидация email |
| Подвал | Социальные ссылки, копирайт |

### Интерактив
- **Кнопка «Показать ещё»** – подгружает 4 новых трека, блокируется после загрузки всех.
- **Тёмная тема** – переключается по клику, состояние сохраняется в `localStorage`.
- **Кнопка «Слушать»** – при клике выводит в консоль и показывает уведомление (демо-режим).
- **Адаптивная сетка** – Grid + медиазапросы для мобильных устройств.

### Форма обратной связи
- Проверка на заполненность имени и сообщения.
- Валидация email (регулярное выражение).
- При успешной отправке данные выводятся в **console.log**, форма очищается.
